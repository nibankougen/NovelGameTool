# NovelEdit — ノベルゲーム シナリオエディタ

ノベルゲームのシナリオデータ（セリフ・地の文・演出コマンド・選択肢分岐）を、キーボード中心の少ない手数で作成できるPC向けエディタです。

## 起動方法

`NovelGameTool.html` をブラウザ（Edge / Chrome など）でダブルクリックして開くだけです。インストール・ネット接続は不要です。

編集内容はブラウザ内に**自動保存**されます。バックアップや別PCへの受け渡しには「JSON保存」を使ってください。

## 基本の書き方

下の入力欄に打って **Enter** を押すだけで行が追加されていきます。

| 入力 | 意味 |
|---|---|
| `こんにちは` | 現在の話者のセリフ |
| `@あかね こんにちは` | 話者を「あかね」に切替えてセリフ追加（未登録の名前は自動でキャラ登録） |
| `@あかね` | 話者の切替のみ |
| `@あかね(笑顔) こんにちは` | 表情付きセリフ。未登録の表情はキャラの表情候補に自動追加（全角`（）`も可） |
| `@ 教室に入った。` | 地の文（ナレーション）。`@` 単体で地の文モードに切替 |
| `//メモ` | コメント行（ゲームデータとしては無視する想定のメモ） |
| `/bg 教室` | 背景変更 |
| `/bgm 日常テーマ` | BGM変更（`/bgm` のみで停止） |
| `/se ドア開閉` | 効果音 |
| `/wait 1000` | ウェイト（ミリ秒） |
| `/jump ルートA` | シーンへジャンプ（未作成のシーン名なら自動作成） |
| `/choice はい>ルートA \| いいえ>ルートB` | 選択肢（`/choice` のみでGUIの編集画面） |

`/` を打つとコマンド候補がポップアップします（↑↓で選択、Tabで補完）。

選択肢とジャンプは、入力欄右の**「選択肢」「ジャンプ」ボタン**からもクリックで挿入できます。

セリフ行の編集（ダブルクリック / 行選択中に Enter）では、話者と表情は**チップ（ボタン）**として表示され、クリックで切り替えられます。入力欄の文頭で `Backspace` を押すと、文字単位ではなく表情→話者の順に**チップごと削除**されます（話者削除で地の文に）。

テキストエディタで書いた台本を入力欄に**まとめて貼り付ける**と、1行ずつ一括追加できます（上記の記法もそのまま解釈されます）。

## キャラクター

キャラクターは内部的に**ID**で管理されるため、後から名前を変えても既存のセリフはすべて追従します。

キャラ一覧の鉛筆アイコン（またはサイドバーの＋アイコン）から開く編集画面で設定できるもの:

- **名前・色**
- **仮サムネイル画像** — イメージ共有用のプレースホルダ。最大256pxに縮小してプロジェクト内に保存され、キャラ一覧とテストプレイの立ち絵に表示されます
- **表情の候補** — カンマ区切りで自由に定義（例: `笑顔, 怒り, 泣き`）。セリフには `@名前(表情)` のほか、話者チップ横の**「表情」ボタン**からクリックでも選べます。選んだ表情は話者を切り替えるまで続きます
- **設定メモ** — 口調・外見・関係性などの制作メモ。キャラ一覧の **矢印アイコン（›）** をクリックすると、その場でメモを開いて確認・編集できます

仮サムネイル・設定メモは制作用データであり、「ゲーム出力」には含まれません。

## 主なショートカット

| キー | 動作 |
|---|---|
| `↑` `↓`（入力欄が空のとき） | 行選択の移動。新しい行は選択行の直後に挿入 |
| `Enter`（行選択中・入力欄が空） | 選択行を編集 |
| `Esc` | 選択解除（挿入位置を末尾へ） |
| `Ctrl+↑` / `Ctrl+↓` | 選択行を上下に移動 |
| `Ctrl+D` / `Delete` | 選択行を複製 / 削除 |
| `Ctrl+1`〜`9` / `Ctrl+0` | 話者切替 / 地の文 |
| `Ctrl+Z` / `Ctrl+Y` | 元に戻す / やり直し |
| `Ctrl+S` | JSONファイルとして保存 |
| `Ctrl+P` | テストプレイ |
| `Ctrl+F` | プロジェクト全体を全文検索 |
| `F1` | ヘルプ |

## 全文検索

`Ctrl+F`（またはツールバーの虫めがねアイコン）で検索パネルが開き、**プロジェクト全体**（全シーンのセリフ・地の文・コメント・背景/BGM/効果音名・選択肢の文・シーン名）を横断検索できます。1文字打つごとに即座に絞り込まれ、`↑` `↓` で結果を選んで `Enter`（またはクリック）で該当シーンの該当行へジャンプします。`Esc` で閉じます。

## 書き出し

| ボタン | 内容 |
|---|---|
| **JSON保存** | 全データ（メモ・仮画像含む）。バックアップ・「読込」での復元用 |
| **ゲーム出力** | 設定メモ・仮サムネイルを除いた `*.game.json`。ゲームエンジン読み込み用。出力前に設定画面が開き、**表情／シーン名／キャラの色／コメント行**を含めるか、整形出力するかを選べます（設定はプロジェクトに保存） |
| **台本TXT** | 人が読みやすいプレーンテキストの台本 |

### ゲーム出力（`*.game.json`）の形式

既定設定（すべてオン）の場合。オフにした項目（`expressions`・`face`・シーンの`name`・`color`・コメント行）は出力から省かれます。

```jsonc
{
  "title": "プロジェクト名",
  "characters": [
    { "id": "abc123", "name": "あかね", "color": "#ff7a7a",
      "expressions": ["笑顔", "怒り"] }                                    // 表情候補の定義
  ],
  "scenes": [
    {
      "id": "def456",
      "name": "オープニング",
      "commands": [
        { "type": "serif",  "chara": "abc123", "text": "こんにちは！",
          "face": "笑顔" },                                                // face は表情付きの行のみ。chara: null なら地の文
        { "type": "bg",     "value": "教室" },
        { "type": "bgm",    "value": "日常テーマ" },                        // value: "" なら停止
        { "type": "se",     "value": "ドア開閉" },
        { "type": "wait",   "value": 1000 },                               // ミリ秒
        { "type": "jump",   "target": "<シーンid>" },
        { "type": "choice", "options": [
            { "text": "はい", "target": "<シーンid>" },                    // target: null なら続行
            { "text": "いいえ", "target": null }
        ]}
      ]
    }
  ]
}
```

「JSON保存」の全データ版は上記に加え、キャラクターに `memo`（設定メモ）と `thumb`（仮サムネイルのdataURL）、コマンドに `{ "type": "comment", "text": "…" }` の制作メモ行を含みます。
